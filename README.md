# Learn Python — Practice Projects

A concise learning guide and a set of practice programs to build Python fundamentals.

## Purpose

This repository is designed for learning Python through short, hands-on projects. Each program focuses on a specific concept you can read about, implement, and test.

## Prerequisites

- Python 3.8+ installed
- Basic command-line knowledge

## Learning Roadmap

1. Python basics: syntax, variables, data types, control flow
2. Data structures: lists, tuples, sets, dictionaries
3. Functions and modules
4. File I/O and exceptions
5. Object-oriented programming
6. Testing and simple scripts

## Practice Programs (suggested order)

- Hello world — simple script to print text
- Reverse string — manipulate strings ([reverse_string.py](reverse_string.py))
- Palindrome checker — strings and conditions
- FizzBuzz — loops and modular arithmetic
- Prime tester — functions and optimization
- File line counter — file I/O
- CSV reader/writer — use `csv` module
- Todo CLI (mini) — argument parsing and persistence
- Classes: simple BankAccount class — OOP basics
- API fetcher — `requests` usage (optional dependency)
- Unit tests — add tests for a couple of above programs

Feel free to add your own files following the naming pattern `exercise_<name>.py`.

## How to run

Run a script with:

```bash
python3 reverse_string.py
```

Replace `reverse_string.py` with any script name.

## How to contribute

- Add a new script or improve an existing one.
- Add a short README section describing the exercise in a subfolder if needed.
